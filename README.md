## ✨ About IntelliPrint Nexus

**IntelliPrint Nexus** is an AI-powered intelligent campus printing platform designed to modernize traditional university printing services.

During examinations, assignment submissions, project deadlines, and short campus breaks, printing centers can experience long queues, manual processing, communication delays, and inefficient printer utilization.

IntelliPrint Nexus brings the complete printing workflow into a unified digital ecosystem:

> 📄 Upload → 🤖 Analyze → ⚙️ Configure → 💳 Pay → 🧠 Optimize → 🖨️ Print → 📱 Track → 🔐 Collect

The platform combines Artificial Intelligence, Machine Learning, Deep Learning, Computer Vision, Predictive Analytics, intelligent queue management, printer recommendation, real-time tracking, QR-based pickup, and administrative analytics.

# 🔬 AI Document Quality Analysis

The AI Document Quality Analysis module evaluates uploaded documents before printing.

The system applies Computer Vision, Image Processing, and Deep Learning techniques to analyze print readiness and identify potential document-quality issues.

### Analysis Pipeline

```text
PDF Document
     ↓
Document Preprocessing
     ↓
Image Extraction
     ↓
Computer Vision Analysis
     ↓
MobileNetV2 Deep Learning
     ↓
Quality Prediction
     ↓
Quality Score
     ↓
Printing Recommendation
```

The analysis supports evaluation of factors such as:

- Document clarity
- Contrast
- Alignment
- Readability
- Resolution
- Image quality
- Overall print readiness

# 🧠 Intelligent Queue & Printer Selection

IntelliPrint Nexus uses available printer information and print-job details to support intelligent printer selection and waiting-time estimation.

```text
Print Job
   ↓
Pages & Print Settings
   ↓
Available Printers
   ↓
Queue Information
   ↓
Printer Status
   ↓
Estimated Waiting Time
   ↓
Recommended Printer
```

This helps distribute printing requests efficiently and provides users with an estimated completion time before printing.

# 💳 Payment & Queue Tracking

After document analysis and print configuration, the system calculates the printing amount according to the selected print settings.

The workflow then proceeds through:

```text
Order Review
     ↓
Payment
     ↓
Payment Confirmation
     ↓
Queue Assignment
     ↓
Printer Processing
     ↓
Live Status Updates
     ↓
Print Completion
```

Users can track information such as:

- Queue position
- Printer status
- Printing progress
- Estimated completion time
- Print-job status
- Pickup information

# 🔐 QR Pickup & Digital Receipt

After the printing workflow, IntelliPrint Nexus provides a secure document collection mechanism using a unique **Pickup ID and QR Code**.

```text
Print Completed

Unique Pickup ID
      ↓
QR Code Generation
      ↓
User Verification
      ↓
Secure Document Collection
      ↓
Digital Receipt
```

The digital receipt maintains relevant transaction and printing information for future reference.

# ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/sufiiishaikh789-boop/IntelliPrint-Nexus.git
cd IntelliPrint-Nexus
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

### 3. Activate the Environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
streamlit run app.py
```

The application will open in your browser through the local Streamlit server.
